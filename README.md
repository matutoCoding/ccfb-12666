# 集装箱码头装卸作业仿真平台

纯浏览器端（TypeScript + 原生 WebGL2，无后端服务）的集装箱码头数字化验证工具，
用于新码头投产前验证装卸工艺与堆场规划。所有计算、渲染、数据持久化与 Excel 导出均在浏览器内完成。

## 运行

```bash
npm install
npm run dev        # 开发服务器（见 vite.config.ts 端口，默认 5199）
npm run build      # 类型检查 + 生产构建，输出 dist/
npm run preview    # 预览生产构建
```

## 六大功能页面

| 页面 | 核心能力 |
|------|----------|
| 码头布局 | 参数化生成平面图（岸线/泊位/岸桥/箱区/车道），多套方案存储切换对比 |
| 泊位计划 | 船期甘特、风力潮汐预警与调整建议、系缆方案设计、逐根缆绳张力/安全系数校核、SVG 带缆图导出 |
| 船舶配载 | 船型档案、贝位图骨架、按目的港/重量/危品隔离自动配载、拖拽换箱、GM/横倾角实时校核、历史航次整版复制 |
| 堆场管理 | WebGL2 三维箱区、万箱分色、占用率/翻箱率统计、最小翻箱取箱顺序规划 |
| 作业仿真 | 岸桥/场桥/集卡联动离散事件仿真、实例化万箱渲染、1x~64x 倍速与快进、排队长度动态显示 |
| 统计报表 | 泊位利用率/岸桥效率/集卡等待/翻箱率日报周报、环比涨跌、浏览器端 Excel 导出 |

## 架构

```
src/
├── types.ts              全局领域类型（数据契约）
├── state/
│   ├── store.ts          响应式状态 + localStorage/IndexedDB 持久化
│   └── seed.ts           1.2 万箱、多船型、多布局演示数据
├── domain/               纯计算领域逻辑（不依赖 DOM，可单测）
│   ├── layout.ts         布局几何 + 道路拓扑 + Dijkstra 最短路
│   ├── stowage.ts        自动配载 + 危品隔离 + 稳性计算
│   ├── mooring.ts        环境力 + 3 自由度弹性系泊缆绳求解
│   ├── operations.ts     任务拆分/重分 + 完工时间 + 船期气象预警
│   ├── yard.ts           箱区统计 + 最小翻箱取箱规划
│   ├── simulation.ts     固定步长仿真引擎（倍速/快进结果一致）
│   ├── reports.ts        日报周报与环比
│   └── excel.ts          SheetJS 浏览器端 xlsx 导出
├── gl/
│   ├── renderer.ts       WebGL2 实例化渲染器（万箱单 draw call、拾取、轨道相机）
│   └── scene.ts          场景构建（地面/箱区/设备/分色）
└── ui/                   页面与 DOM 组件
```

## 关键性能设计

- **实例化渲染**：所有集装箱与设备走 `drawArraysInstanced`，上万实例单次 draw call；
  实例矩阵/颜色/拾取 id 各一个 VBO，每帧 `bufferSubData` 整体更新。
- **静态外壳 + 局部订阅**：应用外壳不订阅高频状态，仿真每帧 setState 不会重建页面或 WebGL 上下文。
- **即时级联重算**：配载/任务改动 → 任务重拆 → 船期与完工时间同步重算，全内存 O(n log n)。
- **确定性仿真**：固定步长引擎，倍速只改变时钟推进量，不改变仿真结果；支持分块快进。
- **持久化降级**：小数据走 localStorage，超配额自动切换 IndexedDB，另支持项目 JSON 导入导出。

## 仿真模型口径（演示标定，落地需按真实设备参数替换）

- 岸桥单箱循环 1.6 min、双箱吊 2.2 min、舱盖板 3 min；集卡行驶 20 km/h
- 系泊：六级别横风 13.8 m/s + 0.8 m/s 横流，3 自由度线性弹性求解，缆绳安全系数限值 1.5、预警 2.0
- 稳性：横稳心半径按矩形水线面 BM=I/V 估算，GM 与横倾角随配载实时计算
